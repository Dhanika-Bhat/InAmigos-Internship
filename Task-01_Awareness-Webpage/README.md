# Task 01 — NGO Awareness Webpage

## Objective
Design and develop an awareness webpage about InAmigos Foundation covering their projects, social impact, and a call-to-action.

## What's inside
- `inamigos_awareness_task1.html` — The complete single-file webpage (HTML + CSS + JS)

## How to view
Just download `inamigos_awareness_task1.html` and open it in any browser (Chrome, Firefox, Edge). No server needed.

## Tech used
- HTML5
- CSS3 (animations, grid, flexbox)
- Vanilla JavaScript (scroll reveal, progress bar animations)

## Sections covered
1. Hero — intro, stats, certifications
2. About — NGO story, founder
3. Projects — all 6 core projects (SEVA, Bachpanshala, Udaan, Prakriti, Jeev, Vikas)
4. Impact — social impact numbers and progress bars
5. Gallery — visual section
6. Call to Action — Donate / Volunteer / Website links
